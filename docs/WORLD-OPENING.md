# Открытие кейса в мире (над привязанным блоком)

## Как это работает

1. Администратор привязывает блок к кейсу — над ним появляется название кейса (TextDisplay).
2. Игрок нажимает ПКМ по блоку → открывается меню **этого** кейса: содержимое, вероятности, ключи, кнопка «Открыть».
3. «Открыть» → обычные проверки (права, ключи, ресурс-пак) + захват точки → тот же розыгрыш и **та же транзакция**,
   что и при открытии командой (ID операции, игрок, кейс, точка, ключи, шляпа или компенсация сохраняются вместе).
4. Только после успешного сохранения меню закрывается и над блоком запускается анимация:
   полоса моделей шляп этого кейса прокручивается, замедляется и останавливается на выигрыше.
5. Выигранная модель увеличивается и вращается, подсвечивается цветом редкости, звучит финальный звук,
   появляются частицы и подпись; игрок получает сообщение. Затем всё временное удаляется, точка освобождается.

Игрока не телепортирует, камеру не поворачивает, движение не блокирует.
`/cases open <кейс>` и обычное меню `/cases` показывают прежнюю анимацию в GUI.
Способ показа определяется **явным контекстом**, переданным из ПКМ по блоку в меню (точка, мир, координаты),
а не расстоянием до ближайшего кейса.

## Привязать блок

Посмотрите на блок (до 6 блоков) и выполните:

```
/hatcases point add <кейс>      — привязать (повторно — перепривязать к другому кейсу)
/hatcases point remove          — убрать привязку блока под прицелом (надпись удаляется)
/hatcases point list            — список точек и их состояние (свободна / идёт открытие)
/hatcases status                — активные анимации, занятые точки, надписи, временные сущности, задачи плагина
```

Блок точки нельзя сломать, взорвать или сдвинуть поршнем.

## Настроить название над блоком

`config.yml → case-labels` (общие настройки) и `cases.yml → <кейс>.label` (для конкретного кейса):

```yaml
case-labels:
  lines: ['{case}', '&7ПКМ — открыть кейс']  # {case} — название кейса из cases.yml с его цветами
  height: 0.45            # над верхней гранью блока
  scale: 1.0
  view-range: 32          # блоков
  background: '#40000000' # #AARRGGBB (AA — прозрачность) или default
  shadow: true
  see-through: false
  billboard: CENTER       # CENTER — поворот к смотрящему; VERTICAL / HORIZONTAL / FIXED
  raise-during-animation: 0.9
```

Название меняется в `cases.yml → name`, затем `/hatcases reload` — надписи обновляются сразу.
Надписи непостоянные (не сохраняются в файлы мира): после перезапуска или повторной загрузки чанка
создаются заново ровно в одном экземпляре. Точки, привязанные к несуществующему кейсу, пишутся в лог.

## Настроить анимацию, звуки и эффекты

`config.yml → world-animation`; любой параметр переопределяется в `cases.yml → <кейс>.world-animation`
(пример — кейс `premium`). Настройки фиксируются в момент старта: `/hatcases reload` не меняет идущую анимацию.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `enabled` | true | false — открытие через блок показывается в GUI |
| `spin-duration-ms` / `result-duration-ms` | 6000 / 3000 | прокрутка / показ результата |
| `visible-models` | 5 | видимых моделей (нечётное) |
| `scroll-items` | 30 | сколько моделей проходит через центр |
| `height`, `spacing` | 0.9, 0.7 | высота полосы над блоком, шаг между моделями |
| `model-scale`, `center-scale`, `winner-scale` | 0.6, 0.8, 1.2 | масштабы |
| `winner-rise`, `rotation-speed` | 0.3, 120 | подъём и вращение (°/с) выигрыша |
| `deceleration-power` | 3.0 | сила замедления (1 — равномерно) |
| `slowdown-at` | 0.75 | когда звучит звук замедления (доля прокрутки) |
| `view-range` | 48 | дальность видимости моделей |
| `model-transform`, `model-yaw-offset` | HEAD, 0 | как отображать модель, доворот |
| `glow-center`, `center-marker` | true, `&e▼` | выделение центра |
| `sounds.start/tick/slowdown/win/duplicate` | см. ниже | `sound`, `volume`, `pitch`, `enabled`; у `tick` ещё `pitch-end` |
| `particles.start/spin/result` | ENCHANT / END_ROD / DUST | `type`, `count`, `offset-x/y/z`, `speed`, `size`, `enabled` |
| `particles.max-per-tick` | 80 | ограничение частиц |
| `result-label.*` | | строки результата и дубликата, масштаб, фон, тень |

Звук `tick` проигрывается при прохождении **каждой** модели через центр — при замедлении интервалы растут сами.
Звуки и частицы локальные (слышат/видят игроки рядом с кейсом), всему серверу не проигрываются.

### Звуки

| Событие | Звук по умолчанию | Есть в паке v6.2 |
|---|---|---|
| начало | `minecraft:custom.mystery_crate.open` | да (`custom/crate_open.ogg`) |
| прохождение центра | `minecraft:custom.mystery_crate.scroll` | да (`custom/crate_scroll.ogg`) |
| замедление | `minecraft:block.note_block.bell` | стандартный звук Minecraft |
| выигрыш | `minecraft:custom.mystery_crate.unlock` (легендарная — `…unlock.mythical` из `rarities.legendary.win-sound`) | да |
| дубликат | `minecraft:custom.currency.tokens` | да (`custom/tokens.ogg`) |

Отдельного звука замедления в паке нет. Чтобы сделать свой: добавьте файл
`assets/minecraft/sounds/custom/crate_slowdown.ogg`, событие в `assets/minecraft/sounds.json`
(`"custom.mystery_crate.slowdown": {"sounds": ["custom/crate_slowdown"]}`) и укажите
`sounds.slowdown.sound: 'minecraft:custom.mystery_crate.slowdown'`.

## Предпросмотр

Посмотрите на привязанный блок и выполните `/hatcases preview [кейс]` (право `qwhatcase.admin.preview`).
Проигрывается полная анимация со случайной наградой кейса: ключи не списываются, награда не выдаётся,
в историю ничего не пишется. Предпросмотр занимает точку так же, как настоящее открытие, и полностью убирает
за собой временные объекты.

## Занятость и прерывания

* На одной точке — одно открытие. Второй игрок получает «Этот кейс сейчас открывает другой игрок. Подождите.»,
  его ключ не списывается; содержимое смотреть можно. Разные точки независимы.
* Игрок не может одновременно открывать кейсы через меню и блоки.
* Точка захватывается до списания ключа и освобождается при любом исходе (успех, ошибка БД, нехватка ключей,
  прерывание).
* Игрок отошёл или сменил мир — анимация доигрывается, награда уже сохранена.
* Игрок вышел — анимация доигрывается для окружающих, итог он увидит при следующем входе (один раз).
* Привязка удалена или перепривязана, мир выгружен, сущности анимации удалены, чанк выгрузился —
  анимация завершается безопасно, итог приходит в чат, точка освобождается.
* Во время анимации чанк удерживается тикетом плагина; тикет снимается при завершении и ошибках.
* Выключение сервера — задачи отменяются, временные сущности и надписи удаляются; итог игрок увидит при входе.
* Без ресурс-пака: при включённой проверке пака кейс не открывается (прежнее сообщение);
  если проверка отключена, а пак не загружен, открытие показывается в GUI вместо мира.

## Метки сущностей

Все сущности плагина помечены PDC `qwhatcase:entity` (`label` / `anim`), `qwhatcase:point` (мир;x;y;z),
временные — ещё `qwhatcase:operation` (ID открытия), а также тегами `qwhatcase`, `qwhatcase_label`, `qwhatcase_anim`.
Плагин удаляет только сущности со своей меткой. Модели в мире — ItemDisplay, их нельзя подобрать.
