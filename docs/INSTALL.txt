MONOLITH: ARSENAL 0.1.13 — установка
=====================================

Требования
----------
* Minecraft Java Edition 1.21.11, Java 21.
* Fabric Loader 0.19.2 или новее (официальный установщик https://fabricmc.net/use/installer/).

└── ValkyrienSkies-Fabric-MC1.21.11-v3.1.1.jar     <- оригинальный Valkyrien Skies (неофициальный порт), НЕ изменён

Порядок установки
-----------------
1. Fabric Loader 0.19.2+ для 1.21.11.
2. Удалите из mods monolith-arsenal-0.1.12.jar и более старые версии.
3. Положите в mods оба файла, указанных выше.
4. Запустите профиль Fabric 1.21.11 на Java 21.

Нормальные сообщения в логе (не ошибки этого мода)
--------------------------------------------------
* "NoClassDefFoundError ... NeoForgeConfigRegistry" — VS пишет это до того, как наш мод подключает его конфиги
  через новый API; затем в логе должно быть "Applied Valkyrien Skies config valkyrienskies-...toml".
* "Config recipe 'vs_eureka:...' failed to build" — рецепты аддона Eureka, который не установлен.

Проверка
--------
/monolith_arsenal physics backend                 -> Valkyrien Skies ...
/monolith_arsenal physics create_test ~ ~5 ~      -> PENDING, затем READY; тело падает и встаёт на землю
/monolith_arsenal physics info <id>               -> позиция, скорость, масса (mass=M)
/monolith_arsenal physics impulse <id> 0 <5*M> 0  -> тело подпрыгивает примерно на 1,3 м (скорость 5 м/с), один раз
/monolith_arsenal physics remove <id>             -> тело и его блоки удалены
/give @s monolith_arsenal:test_weapon, F5          -> поза оружия
/summon monolith_arsenal:animated_test             -> анимированная модель
