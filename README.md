# QWHatCase

Плагин для **Paper 1.21.11**: шляпы + кейсы. Заменяет старый плагин PTrap 1.1.19 (полный перенос,
старый плагин после миграции не нужен) **с сохранением всей его механики шляп**: тыква на голове, Защита IV,
+3 брони, +2 прочности, чары книгами, магазин с покупкой через Telegram, админ-меню `/hat grant`, импорт предметов,
команды `/hat`, `/hat menu`, `/hat grant`, право `qwhats.admin`.

* 281 шляпа из пака (`custom_model_data` 90…370) с постоянными ID, редкостью и категорией;
* личная коллекция, надевание/смена/снятие, восстановление после входа, смерти и перезапуска;
* кейсы с весами, честными вероятностями в интерфейсе и анимацией прокрутки;
* виртуальные ключи по типам, жетоны за дубликаты, каталог шляп за жетоны;
* открытие через блоки в мире, история и журнал действий, миграция данных PTrap;
* SQLite, все списания/начисления — атомарные транзакции; анимация показывает уже сохранённый результат.

## Установка

1. Нужен сервер **Paper 1.21.11** и Java 21. Других зависимостей нет (драйвер SQLite входит в Paper).
2. Остановите сервер, уберите `PTrap-*.jar` (папку `plugins/PTrap/` оставьте для миграции).
3. Положите `dist/QWHatCase-1.0.0.jar` в `plugins/` и запустите сервер.
4. Выложите обновлённый пак `demoraRPuniversal_v6.2_QWHatCase.zip` по прямой ссылке и укажите её в
   `plugins/QWHatCase/config.yml` → `resource-pack.url`, `sha1: fce683382eedc5ed62883f04b2c7e1fe88bcae91`
   — см. [docs/RESOURCE-PACK.md](docs/RESOURCE-PACK.md), изменения пака — [docs/PACK-CHANGES.md](docs/PACK-CHANGES.md).
   Пока URL не задан, пак не проверяется и кейсы открываются без него.
5. Перенесите данные: `/hatcases migrate`, затем `/hatcases migrate confirm` — см. [docs/MIGRATION.md](docs/MIGRATION.md).
6. Выдайте ключи: `/hatcases key give <игрок> basic 5`.

## Файлы конфигурации (`plugins/QWHatCase/`)

| Файл | Содержимое |
|---|---|
| `config.yml` | характеристики шляп (`hat-item`), магазин Telegram (`donate-shop`), редкости и компенсации, поведение при надетом шлеме, ресурс-пак, объявление, миграция |
| `hats.yml` | каталог шляп (ID, название, описание, редкость, категория, модель, старые ID) |
| `cases.yml` | кейсы: награды и веса, ключи, анимация, звуки, сообщения, компенсация, права (3 примера) |
| `shop.yml` | цены каталога за жетоны |
| `messages.yml` | все тексты интерфейса (локализация) |
| `data.db` | база SQLite |

После правки — `/hatcases reload`. Ошибочная конфигурация не применяется; ошибочный кейс отключается отдельно.

## Сборка из исходников

```
./gradlew build        # тесты + JAR в build/libs/QWHatCase-1.0.0.jar
```

Требуется JDK 21. Инструменты: `tools/generate_catalog.py` (каталог из пака), `tools/validate_pack.py` (проверка пака),
`tools/update_pack.py` (сборка пака v6.2 из v6.1).

## Не входит в первую версию

Физические ключи-предметы, обмен между игроками, гарантия после серии открытий, массовое открытие,
сезонные/ротационные предложения, отдельный 3D-предпросмотр, голограммы над точками, MySQL.
Одновременное ношение шлема и шляпки не поддерживается (PTrap тоже использовал слот шлема) — см. AUDIT.md.
